# 日本使用边界与隐私设计

核对日期：2026-10-31。本文件记录产品的限制措施，不是对任意使用行为作法律保证。是否获得授权、网络/服务规则、具体使用方式仍会影响判断；公开发布或商业服务需另行评估适用义务。

## 功能范围
- 默认仅读取本机当前默认上网网络状态，并由用户主动请求普通 DNS、单一目标 TCP、HTTPS HEAD 或专用下载测速服务。支持依法获准使用的家庭/办公/公共Wi-Fi、移动网络、以太网等环境，不表示有权检查这些网络中其他设备。
- 默认主机是 www.cloudflare.com:443，不自动执行网络请求。下载测速另行确认服务器、计费网络与最多100MB读取预算。遵守服务端响应，不绕过403/认证门户，不尝试避开限流或付费认证。
- 网关检查只有用户单独确认拥有/获管理员授权后启用，且仅允许当前Wi-Fi/以太网的私有IPv4默认网关；每次最多3次系统ICMP及各1次80/443 TCP建连，两次检查至少间隔30秒。公共网络管理接口不默认授权，VPN/移动网络不执行网关管理接口探测。
- 不扫描IP网段、不嗅探他人通信、不读取凭据、不猜密码、不自动登录、不越过访问控制、不利用漏洞，不修改路由器设置，不生成破坏性流量。
- Android Wi-Fi扫描仅请求系统公开接口读取可见AP广播，不关联未知AP，不破解加密，不绕过扫描权限或节流。

日本警察厅对不正访问的说明涉及使用他人ID/密码及非法侵入；本产品以不实施这些行为、限定授权目标为设计边界，不能据此把所有探测行为一概断言为合法或违法。依据：[警察厅不正访问对策](https://www.npa.go.jp/bureau/cyber/countermeasures/unauthorized-access.html)，[e-Gov 不正アクセス行為の禁止等に関する法律](https://laws.e-gov.go.jp/law/411AC0000000128)。

## 定位与数据
- 定位仅针对本机，默认不采集；用户阅读说明并同意后，使用前台系统定位，一次最多15秒，可取消。无后台定位权限和轨迹记录服务。
- 可只授权大致位置；精确定位/定位服务另会影响Wi-Fi扫描。室内房间靠手动命名，不将GPS当作房间定位。
- 记录坐标、系统报告精度、定位采集时间及模拟位置标记。只将2分钟内的附加坐标带入新测量；无新鲜位置就留空。
- 坐标、位置名称、备注、SSID/BSSID和设备列表不由本应用上传到测速服务器。系统定位提供者可能依赖其自身网络服务，此行为不应被描述为完全离线。
- 数据位于本机应用私有Room库，禁用备份/设备迁移；当前JSON/CSV快照导出不含位置记录，默认还会移除可能含网络标识的自由文本。可移除待附加坐标、清除全部历史或卸载。

日本个人信息保护委员会说明：可识别特定个人（含容易与其他信息对照）的位置信息可能属于个人信息，并提醒注意第三方应用的位置提供。依据：[PPC 第三方平台/应用使用注意事项](https://www.ppc.go.jp/news/careful_information/use_AP_provided_by_3rdparty/)。因此本版采用前台同意、本机保存、明确用途和删除入口，不把定位作为强制联网检测前提。
