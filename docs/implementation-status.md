# 实施状态

## Phase 1：基础版本
已实现项目/Gradle wrapper、Compose Material3、Hilt、ViewModel/Flow、系统权限入口、当前 Wi-Fi 指标、RSSI 1/2/5秒前台图、频段信道、Tx/Rx、IPv4/IPv6前缀/网关/DNS、首页、TCP/DNS基础检测、Room 手动快照。

部分：当前频宽通过 AP 扫描结果查看，未自动合并至快照；DHCP详细租期/完整网络能力尚未提供；综合评分当前仅RSSI；历史尚未保存所有连续样本。硬件运行验收未完成。

## Phase 2：部分实现
已实现附近AP手动扫描、系统广播、限频提示/缓存时间、SSID分组、信道分布、RSSI参考图与连接/BSSID事件；拥挤指数为估计。
待实现：可切换RSSI排序/分组模式、频宽重叠曲线、更多漫游判断、持续历史与可靠置信度建议。

## Phase 3：部分实现
已实现网关/指定目标TCP、最小/最大/平均/中位/P95/Jitter/失败率，系统DNS计时及地址，取消与Wi-Fi绑定。
待实现：HTTP/TLS分阶段、DNS多次稳定性/指定DNS/DoH、下载上传吞吐、Windows配套HTTP服务或iperf3、持续1/5/15/30分钟监控、性能曲线和可用的traceroute。未使用小文件伪装测速。

## Phase 4：未实现
没有设备发现、设备持久身份/标签、NSD/SSDP、拓扑、管理接口审计、安全分数。需要另行建立有限扫描授权与取消/速率策略、设备身份证据及路由器人工验证模型。基础安全类型读取与Open/WEP提示已提供。

## Phase 5：未实现
没有平面图、多楼层、采样位置、热力图或覆盖比较。需先完成真实采样持久结构、楼层/坐标与低置信区域模型。

## Phase 6：部分基础
已有简单本地确定性提示、快照历史、脱敏JSON/CSV。未实现完整诊断规则数据结构、综合健康/安全评分、PDF、历史比较及全量英日翻译。资源目录已预留。避免输出缺乏实际测量的综合报告。

后续功能未作为空按钮暴露。优先维护当前真实检测的可构建版本。

基础版 APK 已实际构建，9项单元测试、3项模拟器集成测试通过，Lint 0错误。安装与冷启动已验证；详细证据见 [testing.md](testing.md)。源代码通过 Git 管理。


## 0.2.0 增量
首页增加简明信号/上网状态/下载体验说明。通过用户确认后的 Wi-Fi 绑定 HTTPS 单连接下载测量参考速度，显示实时累计速率、最终 Mbps/MB/s、时长、流量、服务器与时间；可停止、保存本次结果。样本不足不评分，弱信号不自动认定低网速。此项替代上述 Phase3「下载吞吐」的未完成状态；上传、iperf3、多连接测速仍未实现。

位置记录：支持名称/备注、手动记录信号、下载完成自动保存位置测量、历史列表修改名称备注，数据库v1→v2非破坏性迁移。尚无平面图坐标或楼层模型。位置记录导出尚未实现，界面明确提示。


## 0.3.0 增量
实现默认主机/HTTPS响应解释、当前默认Wi-Fi/移动/以太网/VPN网络检测、计费提示、有限授权网关ICMP+80/443降级、IPv4/IPv6多地址TCP尝试、重复事件过滤、扫描权限入口/等待超时/无数据拥挤状态。实现可选前台本机定位与本地历史存储、精度/时间/模拟标记，以及Room v1/v2→v3迁移。用户授权和网络服务条款是使用前提；无网段扫描或认证攻击。未实现蜂窝射频指标、全环境硬件验证、室内自动房间识别、地图或位置导出。
