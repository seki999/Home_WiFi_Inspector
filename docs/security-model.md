# 安全与隐私模型

无账号、无云数据库、无遥测、无广告 SDK、无自动外部探测。检测目标由用户输入；DNS/TCP 操作前必须勾选网络授权。扫描附近无线 AP 使用系统公开 API，不连接 AP。应用当前不扫描 IP 网段、不发现或标记入侵者，不自动登录路由器，不发送认证凭据，不修改配置。

TCP每次5个UI逻辑样本（底层接口最多30），每个样本最多4个地址候选、单地址1.2秒超时、样本间隔300ms；最多单一测试任务。用户可取消，后台生命周期自动取消；取消会直接关闭当前socket。系统 DNS 使用 5 秒超时和取消信号。

Room 数据在应用私有目录，allowBackup=false。JSON/CSV 通过系统创建文档选择器导出，无存储全盘权限。默认脱敏会移除 SSID、BSSID、设备描述和整个自由文本详情，因为该文本可能包含内部 IP、DNS 或目标地址；保留时间/RSSI/频率。关闭脱敏后导出包含网络标识，应由用户选择保存位置。CSV 字段转义双引号，并对常见公式前缀加单引号。

当前规则仅对已知 Open/WEP 和可见网络状态给建议；不提供完整安全分数。未经测试的路由器设置一律不视为已检查。安全中心、LAN 发现的完整授权和身份模型留待 Phase4。


0.2.0：新增手动 HTTPS 下载测速。确认框明确服务器、公网IP可见性和最多100MB读取预算；请求不附带账号/认证，不跟随重定向，不重试，不缓存响应，不接受压缩字节充当真实吞吐。连接绑定Wi-Fi，用户取消调用OkHttp Call.cancel，后台及连接标识/IP变化时取消。默认请求Cloudflare专用下载端点，只有用户点同意后发送。所有结果是单连接参考，不做ISP故障断言。


0.3.0：遵循当前默认网络检测，移动/计费环境下载须明确确认。确认框的网络ID及计费状态会传入检测流程，开测前重新核对，并在读取时检查网络及计费状态，不在原网络消失后擅自继续传输。新增HTTPS HEAD和自有私有网关有限检查；后者独立勾选授权，间隔30秒、预定义端口，无管理页登录或配置读取。新增可选的本机前台定位，提供者并行请求、首个新鲜结果取消其他请求，整体15秒超时；坐标只存本机位置表、默认不导出，不建立持续轨迹。详情与日本官方来源见[japan-use-boundaries.md](japan-use-boundaries.md)。
